# 📱 Инструкция по настройке SMS-рассылки

## Обзор

Проект поддерживает несколько вариантов отправки SMS:
1. **Эмуляция** (по умолчанию) - для тестирования без реальных SMS
2. **SMS.ru** - популярный российский сервис
3. **SMSC.ru** - еще один российский сервис

---

## 🎯 Вариант 1: Эмуляция (для тестирования)

**Подходит для:** разработки, тестирования, демонстрации проекта

**Настройка:**
1. Откройте файл `config.php`
2. Убедитесь, что установлено:
   ```php
   define('SMS_PROVIDER', 'emulation');
   ```

**Особенности:**
- ✅ Не требует регистрации
- ✅ Не тратит деньги
- ✅ Работает сразу
- ❌ Не отправляет реальные SMS

---

## 📲 Вариант 2: SMS.ru (рекомендуется для студентов)

**Подходит для:** реальной отправки SMS в России

**Шаги настройки:**

### Шаг 1: Регистрация
1. Перейдите на https://sms.ru
2. Зарегистрируйтесь (можно использовать бесплатный тестовый режим)
3. Войдите в личный кабинет

### Шаг 2: Получение API ID
1. В личном кабинете перейдите в раздел "API"
2. Скопируйте ваш **API ID** (выглядит как строка символов)

### Шаг 3: Настройка в проекте
1. Откройте файл `config.php`
2. Найдите строки:
   ```php
   define('SMS_PROVIDER', 'emulation');
   define('SMSRU_API_ID', '');
   ```
3. Измените на:
   ```php
   define('SMS_PROVIDER', 'smsru');
   define('SMSRU_API_ID', 'ваш_api_id_здесь');
   ```
4. Сохраните файл

### Шаг 4: Тестирование
1. Откройте форму отправки SMS в вашем проекте
2. Выберите получателя с реальным номером телефона
3. Отправьте тестовое SMS
4. Проверьте, пришло ли сообщение

**Стоимость:**
- Тестовый режим: бесплатно (ограниченное количество SMS)
- Обычный режим: ~2-3 рубля за SMS

**Документация:** https://sms.ru/api

## 📲 Вариант 3: SMSC.ru

**Подходит для:** реальной отправки SMS в России

**Шаги настройки:**

### Шаг 1: Регистрация
1. Перейдите на https://smsc.ru
2. Зарегистрируйтесь
3. Войдите в личный кабинет

### Шаг 2: Настройка в проекте
1. Откройте файл `config.php`
2. Найдите строки:
   ```php
   define('SMS_PROVIDER', 'emulation');
   define('SMSCRU_LOGIN', '');
   define('SMSCRU_PASSWORD', '');
   ```
3. Измените на:
   ```php
   define('SMS_PROVIDER', 'smscru');
   define('SMSCRU_LOGIN', 'ваш_логин');
   define('SMSCRU_PASSWORD', 'ваш_пароль');
   ```
4. Сохраните файл

**Документация:** https://smsc.ru/api/

---

## 🔧 Как переключиться между провайдерами

В файле `config.php` измените значение `SMS_PROVIDER`:

```php
// Для эмуляции
define('SMS_PROVIDER', 'emulation');

// Для SMS.ru
define('SMS_PROVIDER', 'smsru');

// Для SMSC.ru
define('SMS_PROVIDER', 'smscru');
```

## ⚠️ Важные замечания

1. **Безопасность:**
   - Не публикуйте файл `config.php` в открытом доступе
   - Не коммитьте API ключи в Git без использования `.gitignore`

2. **Формат номеров:**
   - Система автоматически форматирует номера (убирает + и пробелы)
   - Поддерживаются номера в форматах: `+79001234567`, `89001234567`, `79001234567`

3. **Лимиты:**
   - У каждого провайдера есть лимиты на отправку
   - Проверяйте баланс в личном кабинете

4. **Тестирование:**
   - Сначала протестируйте на своем номере
   - Убедитесь, что SMS доставляются корректно

## 🐛 Решение проблем

### SMS не отправляются

1. **Проверьте конфигурацию:**
   - Убедитесь, что `SMS_PROVIDER` установлен правильно
   - Проверьте, что API ключи/логины указаны верно

2. **Проверьте баланс:**
   - Войдите в личный кабинет провайдера
   - Убедитесь, что есть средства на счету

3. **Проверьте логи:**
   - В базе данных таблица `messagelogs` содержит статусы отправки
   - Проверьте таблицу `system_logs` для детальной информации

4. **Проверьте номер телефона:**
   - Убедитесь, что номер указан правильно
   - Номер должен быть в формате: `79001234567` (без +)

### Ошибка "Не указан API ID"

- Убедитесь, что в `config.php` указан `SMSRU_API_ID` (для SMS.ru)
- Или `SMSCRU_LOGIN` и `SMSCRU_PASSWORD` (для SMSC.ru)

### Ошибка соединения

- Проверьте интернет-соединение
- Убедитесь, что сервер может делать исходящие HTTP-запросы
- Проверьте, не блокирует ли firewall запросы
