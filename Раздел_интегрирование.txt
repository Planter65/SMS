Раздел: Интегрирование

Назначение интеграционного модуля
Компонент `integration.php` предоставляет административный интерфейс для валидации служебных строк интеграции (логины операторов, названия групп рассылок, ФИО получателей). Он был создан, чтобы до фактической отправки сообщений гарантировать, что идентификаторы соответствуют корпоративным требованиям по безопасности и действительно присутствуют в базе данных. Проверка доступна только администраторам (`requireRole('admin')`), что предотвращает массовый перебор значений со стороны обычных пользователей.

Механика работы
После нажатия кнопки в браузере JavaScript собирает введённую строку, предварительно проверяет локальные критерии (длина, наличие регистров, цифр и спецсимволов) и отправляет AJAX‑запрос на этот же PHP‑скрипт. Серверная часть заново оценивает критерии и дополнительно ищет совпадение в трёх таблицах (`users`, `recipients`, `groups`). Результат возвращается в JSON и мгновенно отображается в интерфейсе: индикаторы критериев перекрашиваются, а блок `match-result` показывает, где именно найдено совпадение либо сообщает об отсутствии записи.

Использованные технологии
1. PHP 8 + расширение mysqli — синхронное подключение к БД и подготовленные запросы.
2. CSS/HTML + Font Awesome — визуализация карточки с прогресс-блоками критериев.
3. Vanilla JavaScript (Fetch API и FormData) — обмен с сервером без перезагрузки страницы и живая подсветка критериев прямо в браузере.

Ключевые фрагменты
PHP-валидация критериев и поиск в БД:
<?php
if ($_SERVER['REQUEST_METHOD'] === 'POST' && ($_POST['action'] ?? '') === 'validate_integration') {
    $criteria = [
        'length' => mb_strlen($payload) >= 12,
        'upper' => preg_match('/[A-ZА-Я]/u', $payload) === 1,
        'lower' => preg_match('/[a-zа-я]/u', $payload) === 1,
        'digit' => preg_match('/\d/', $payload) === 1,
        'special' => preg_match('/[^A-Za-zА-Яа-я0-9]/u', $payload) === 1,
    ];
    foreach ($sources as $source) {
        $stmt = $conn->prepare($source['sql']);
        $stmt->bind_param('s', $payload);
        ...
    }
    echo json_encode(['criteria' => $criteria, 'match' => $matchDetails]);
}
?>

Клиентский JavaScript, который синхронизирует локальные проверки с серверными:
const localCriteria = {
    length: value => value.length >= 12,
    upper: value => /[A-ZА-Я]/.test(value),
    lower: value => /[a-zа-я]/.test(value),
    digit: value => /\d/.test(value),
    special: value => /[^A-Za-zА-Яа-я0-9]/.test(value)
};
fetch('integration.php', {
    method: 'POST',
    body: formData
})
.then(response => response.json())
.then(data => {
    refreshCriteriaBoard(data.criteria || {});
    showStatus(data.message || '', data.criteria?.db_match);
});

Микровывод
Интеграционный раздел замыкает цепочку контроля данных: он сочетает моментальную клиентскую валидацию и гарантированный серверный поиск по базе, поэтому администратор уверенно связывает внешние системы с СМС-платформой без риска ошибочной идентификации.
