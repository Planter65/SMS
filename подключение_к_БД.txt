ПОДКЛЮЧЕНИЕ К УДАЛЁННОЙ БАЗЕ ДАННЫХ

1. Получите у преподавателя логин и пароль для доступа к MariaDB.
2. Откройте phpMyAdmin по адресу https://134.90.167.42:10307 и убедитесь, что соединение устанавливается.
3. В проекте откройте файл `config.php` и укажите параметры подключения:
   - `DB_HOST = '134.90.167.42';`
   - `DB_PORT = 10306;` (используется из серверного кода)
   - `DB_NAME = 'ria_spektr';`
   - `DB_USER = 'student_login';`
   - `DB_PASSWORD = 'student_password';`
4. Подключение выполняется через PDO/MySQLi с обязательной установкой кодировки `utf8mb4` и обработкой исключений.

Пример кода (файл `db.php`):
<?php
class Connection
{
    public static function make($host, $port, $db, $user, $pass)
    {
        $dsn = "mysql:host={$host};port={$port};dbname={$db};charset=utf8mb4";
        $options = [
            PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
            PDO::ATTR_EMULATE_PREPARES   => false,
        ];

        return new PDO($dsn, $user, $pass, $options);
    }
}
?>
