---

## 🚀 Быстрый старт

### Вариант 1: Тестирование (без реальных SMS)

1. Откройте `config.php`
2. Убедитесь, что установлено:
   ```php
   define('SMS_PROVIDER', 'emulation');
   ```
3. Готово! Можно тестировать систему.

### Вариант 2: Реальная отправка через SMS.ru

1. Зарегистрируйтесь на https://sms.ru
2. Получите API ID в личном кабинете
3. Откройте `config.php` и измените:
   ```php
   define('SMS_PROVIDER', 'smsru');
   define('SMSRU_API_ID', 'ваш_api_id');
   ```
4. Сохраните и протестируйте!

## 🔧 Настройка

Все настройки SMS находятся в файле `config.php`:

```php
// Тип провайдера: 'emulation', 'smsru', 'smscru'
define('SMS_PROVIDER', 'emulation');

// Для SMS.ru
define('SMSRU_API_ID', '');

// Для SMSC.ru
define('SMSCRU_LOGIN', '');
define('SMSCRU_PASSWORD', '');
```

## 💡 Важно

- **Для тестирования** используйте режим `emulation` - он не отправляет реальные SMS
- **Перед массовой рассылкой** протестируйте на своем номере
- **Проверяйте баланс** в личном кабинете провайдера
- **Не публикуйте** файл `config.php` с API ключами в открытом доступе
